# 顶部提示改为浮动胶囊（不挤占内容）—— 2026-10-18

## 用户诉求

> 测速或者刷新的时候顶部会有提示，正在测速、测速完成等，每次都会把其他内容挤占一行，
> 不要挤占，直接在顶部中间显示就行了，不要把空间往下挤。

## 根因

`SubscriptionPage.build()` 里，提示是一个**参与布局的条件 Text**，放在 `Scroll` 的
`Column` 内、导航栏之后：

```ts
if (this.toastVisible) {
  Text(this.toastMsg)            // 「正在测速…」「✓ 测速完成」「刷新完成…」
    .fontSize(11.5) ... .margin({ top: 8, bottom: 8 })
}
```

条件成立时它占掉一行（约 8+22+8vp），条件消失时又收回 —— 于是每次点闪电测速/刷新，
概览卡与所有订阅卡都会先下移一行再弹回；连续测速时列表持续跳动。
提示语来源是 `showToast()`：`正在测速…` / `✓ 测速完成` / `✓ 已刷新「…」及节点测速` 等。

## 修复

把它从内容流里搬出来，作为页面根 `Stack` 的**最后一个子节点**（叠层），
位置固定在顶部中间，完全不参与 `Column` 布局：

```ts
Stack({ alignContent: Alignment.Bottom }) {
  Column() ...                      // 背景
  Column() { Scroll() ... }         // 内容（不再含提示行）
  if (this.toastVisible) {          // ← 新增：浮动提示层
    Column() {
      Text(this.toastMsg) ... .constraintSize({ maxWidth: '88%' })
    }
    .width('100%').height('100%')
    .padding({ top: TunBoxGeometry.navHeight + 8, left: 16, right: 16 })
    .justifyContent(FlexAlign.Start)
    .alignItems(HorizontalAlign.Center)
    .hitTestBehavior(HitTestMode.None)   // 不拦截触摸
    .zIndex(20)
  }
}
```

细节：
- 顶部内边距 = 导航栏高（56vp）+ 8 → 胶囊落在导航栏正下方居中，不遮标题与右上按钮；
- `hitTestBehavior(HitTestMode.None)` → 提示层与子节点都不参与命中测试，
  不会挡住底下的订阅卡/按钮（2.4s 自动消失期间的点击照常生效）；
- `maxLines(2)` + `Ellipsis` + `maxWidth 88%` → 长文案（如「刷新完成，共 N 个节点；
  某个订阅: 原因」）不会撑破屏幕；
- `TransitionEffect.OPACITY` 160ms 淡入淡出，视觉上不突兀；
- 阴影 + 0.92 不透明底色：叠在卡片上仍然可读。

## 追加：配色改为跟随主题（同日用户反馈「黑底不搭」）

**用户原话**：> 这个提示是黑色底色，跟软件整体颜色不匹配，你改一下底色，和提示的字体颜色。

**问题**：首版用了写死的 `rgba(15, 23, 42, 0.92)` 深黑底 + 纯白字 —— 这是「系统 toast」的
观感，但本应用浅色主题是「白卡 + 品牌蓝」体系，一块黑色胶囊浮在白卡上非常突兀。

**修复**：配色不再写死，改由 `TunBoxColors` 提供主题令牌（新增 4 个 getter）：

| 令牌 | 浅色 | 深色 |
|---|---|---|
| `toastBg` | `#FFFFFF`（与订阅卡同一种卡片白） | `rgba(20, 28, 46, 0.94)`（深卡底） |
| `toastText` | `#111827`（正文墨黑） | `#F8FAFC`（近白） |
| `toastBorder` | `#D0E1FD`（品牌蓝浅描边） | `rgba(59, 130, 246, 0.42)` |
| `toastShadow` | `rgba(10, 89, 247, 0.16)`（与底栏投影同源） | `rgba(0, 0, 0, 0.60)` |

字形由 `Bold` 降为 `Medium`：白底黑字用 Bold 会显得比周围正文更重，Medium 更贴合卡片文案。
描边保留 1vp：白色胶囊叠在白色卡片上时靠它勾轮廓，否则边界发虚。

**真机验证**：浅色（白胶囊/黑字/蓝边）与深色（深卡底/浅字/蓝边）两套均截图确认；
切换主题用主页右上角太阳按钮，验证完已把主题偏好恢复为「跟随系统」。
